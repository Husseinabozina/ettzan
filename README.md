# etzan — Life Coaching Flutter App

A complete Flutter UI starter based on the 25-screen Etzan life-coaching concept. The project is designed as a scalable product foundation rather than a collection of disconnected mockups.

## Included

- 25 routed screens covering onboarding, authentication, coaching, booking, goals, habits, planning, journal, analytics, chat, resources, subscription, profile, and settings.
- Arabic-first UI with runtime Arabic/English switching.
- Automatic RTL/LTR direction through Flutter localization delegates.
- Responsive phone, tablet, and desktop layouts.
- Bottom navigation on phones and an adaptive navigation rail on larger screens.
- Centralized colors, typography, spacing, radii, gradients, shadows, and breakpoints.
- Reusable cards, buttons, tags, progress indicators, avatar, metric, grid, empty-state, and page-shell widgets.
- Light and dark themes.
- Interactive demo behavior for forms, filters, booking, habits, journal mood, chat, subscription plans, notifications, and settings.
- No third-party runtime packages. This keeps the starter fast, auditable, and easy to integrate with Bloc, Riverpod, Dio, Firebase, or your own backend later.

## Run

The repository contains the complete Flutter source and design references. Because platform shells are generated by the installed Flutter SDK version, run this once after extracting:

```bash
./tool/bootstrap_platforms.sh
flutter run
```

If the project is copied into an existing Flutter app, `flutter pub get && flutter run` is enough.

Use Flutter 3.32+ and Dart 3.6+.

## Architecture

```text
lib/
├── app/
│   ├── app.dart
│   ├── app_router.dart
│   └── settings_controller.dart
├── core/
│   ├── design_system/
│   ├── localization/
│   ├── navigation/
│   ├── responsive/
│   └── widgets/
└── features/
    ├── auth/
    ├── coaching/
    ├── growth/
    ├── journal/
    └── account/
```

The demo currently focuses on the presentation layer and product system. The folder structure is ready to grow each feature into:

```text
feature/
├── data/
│   ├── data_sources/
│   ├── models/
│   └── repositories/
├── domain/
│   ├── entities/
│   ├── repositories/
│   └── use_cases/
└── presentation/
    ├── controllers/
    ├── screens/
    └── widgets/
```

See `docs/ARCHITECTURE.md` and `docs/DESIGN_SYSTEM.md`.
